# Rundingan Kreasi Media

Integrated media and creative business platform.

## Business units
- Rundingan Media
- Rundingan Academy
- Rundingan Rental
- Rundingan Production
- Rundingan Creative
- Rundingan Event
- Corporate Management

## Architecture
- Next.js and TypeScript web platform
- Neon PostgreSQL shared source of truth
- Modular monolith and API-first architecture
- Offline-capable desktop client planned with Tauri, SQLite and sync queue

## Development
Use the Neon development branch for schema changes. Never commit secrets. Production data must not be changed by development migrations.
